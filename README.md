# 🎨 Pavona Studio - Ready to Use!

## 🚀 Quick Start (3 Steps)

### 1. Start Servers
```bash
# Terminal 1
npm run dev

# Terminal 2
php artisan serve
```

### 2. Open Browser
Visit: **http://localhost:8000**

### 3. Login to Admin Panel
Click "Login" button or visit: **http://localhost:8000/login**
